# PA-01B2：页面协助协议与刷新保护

本分支属于独立 Agent 线，不涉及 2D 或业务主线合并。

## 边界

新增 Host 通用 assistance 请求适配、结果关联判断和原生表单草稿保护，导出于 app-host/index.ts。平台业务能力、权限和写入继续由平台服务端负责。Run 成功不是业务写入凭证。

只在请求编号、任务类型、来源页面/路由/动作、Run 编号及成功状态全部匹配，且仍为同一页面挂载实例、没有草稿修改时允许刷新。离开后重新打开同一路径也不刷新；失败、暂停、取消、旧格式结果均不刷新。有未保存内容时保留页面并提供中英文提示。

草稿跟踪覆盖原生 input/textarea/select 的事件及值快照；编辑后回改仍保守视为脏。自定义富文本编辑器尚需独立 dirty 接口，不能宣称已覆盖。

## 平台接入

EVO-App-Platform 的 vendor Host 已有上游当前主线没有的 contextual transport，因此本次只同步此新增 helper 与导出/文案，并在平台现有适配层做最小接线，不整体覆盖上游 page-controller 或 shell。后续应单独治理该历史差异。

## 验证

新增 14 项 Node 测试覆盖请求适配、关联不匹配、终态、挂载实例、草稿事件/快照与监听器释放。测试使用可控 DOM 替身，并非真实浏览器验收。平台另有实际 thread transport 测试。PR CI 负责完整 TypeScript 构建及回归；真实浏览器验收仍需完成。

# Experience Invariants
1. Business truth does not change because presentation changes.
2. Decision-critical evidence remains available.
3. Shared reference remains stable during collaboration.
4. Accessibility may override cosmetic preference.
5. Organization/safety policy overrides personal preference.
6. Personalization is reversible and resettable.
7. Adaptation should converge toward fit rather than continuously perturb.
8. Semantic attention importance is distinct from presentation.
9. Motion intent is semantic; concrete animation is renderer-specific.
10. EC owns long-term personal learning; Eidos does not silently create a competing profile.
11. Standard deterministic fallback works without EC.
12. Arbitrary generated executable code is not a Core Runtime personalization mechanism.

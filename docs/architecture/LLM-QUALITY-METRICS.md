# LLM-Native Quality Metrics

Eidos evaluates more than runtime correctness.

## LLM Error Surface
How many plausible but wrong choices can an LLM make?

Lower is better.

## Context Requirement
How much repository context must an LLM load to make a safe local change?

Lower is better.

## Generated Code Volume
How much new code must an LLM produce for a common experience?

Lower is better.

## Deterministic Validation Coverage
How much correctness can tools prove without asking an LLM to reason?

Higher is better.

## Composition Reuse
How often can intent be satisfied by composing existing capability contracts?

Higher is better.

## Repair Cycles
How many generation/fix iterations are required before a valid experience?

Lower is better.

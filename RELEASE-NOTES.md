# Release Notes — 1.0.0-candidate.1

This candidate turns the previous Architecture Convergence package into a self-contained LLM-first Eidos reference repository.

## Added

- Founder-confirmed Constitution including adaptive-yet-stable experience principles.
- Machine-readable LLM repository map.
- Deterministic Capability Catalog and discovery API.
- Experience stability model: invariant / shared-stable / personal-stable / adaptive.
- Standard / Role / Personal / Shared experience modes.
- ExperienceContext and ExperienceComposition contracts.
- EC boundary contracts and expectations.
- Attention semantics distinct from attention presentation.
- Motion semantics distinct from renderer-specific animation.
- Shared Core / Personal Periphery collaboration primitives.
- Constrained page customization validator.
- Decision/evidence model primitives.
- Candidate capability families for decision, exception and collaboration experiences.
- Deterministic repository validation tooling.
- Additional architecture tests.

## Preserved

- convergence runtime
- UIDL 0.1.1 profile
- ActionRequest boundary
- VNode/HTML bridge work
- TreeSelect controlled state-machine convergence
- migration/ADR documentation

## Direction

The next implementation work should promote existing Form/Table/DatePicker/Upload/Dialog assets into explicit capabilities, add renderer compatibility negotiation, and implement richer decision/exception renderers without weakening the Host/business-truth boundary.

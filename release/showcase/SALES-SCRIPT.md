# 7-Minute Sales Script

**0:00 — Problem**  
"AI can generate UI code, but every generated hook, callback and framework option is another place it can be plausibly wrong."

**0:45 — Eidos**  
"Eidos gives an LLM a bounded, machine-discoverable toolbox. It composes capabilities; it does not need to reinvent a front end."

**1:30 — Executive Cockpit**  
"This is not a generic dashboard. It is an exception and decision experience: evidence, impact and a bounded human choice."

**2:30 — Direct manipulation**  
"For a simple preference, asking an LLM is slower than dragging. Eidos keeps direct manipulation first-class and stores it through the same constrained state model."

**3:15 — LLM pipeline**  
"The LLM is not trusted as the runtime. It proposes a versioned contract."

**4:00 — Break it**  
Inject an invalid capability.  
"Eidos rejects the proposal deterministically. We use intelligence where intelligence helps, and deterministic machinery where guarantees are possible."

**5:00 — EC and personalization**  
"EC learns the person. Eidos realizes the bounded adaptation. Personalization converges toward fit; it does not continuously rearrange the product."

**5:45 — Shared mode**  
"When people collaborate, shared truth and reference remain stable."

**6:15 — Breadth**  
"Forms, BI, reports, diagrams and 3D are different renderer domains under one Constitution."

**6:50 — Close**  
"LLM proposes. Eidos validates. Humans decide. Host executes."

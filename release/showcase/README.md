# Eidos Commercial Showcase

Open `index.html` directly in a modern browser.

The showcase is intentionally zero-dependency so a buyer can receive the ZIP and run it without credentials or a build.

## What to demonstrate

1. Start on Executive Cockpit: show decision/exception-oriented experience.
2. Click **Customize layout** and drag cards: prove direct human manipulation.
3. Open **LLM → Experience**.
4. Generate a proposal: show capability discovery and explicit contract.
5. Click **Inject invalid capability**: prove deterministic fail-closed validation.
6. Switch persona to Shared Review: explain shared-core/personal-periphery.
7. Open Capability Explorer and Beyond Forms: show platform breadth.

The local producer is explicitly a simulator. A production LLM/EC adapter only needs to emit the same proposal contract.

# Evaluation Answer Key

This file is for evaluators, not for the model being tested.

Key expectations:

- Eidos = LLM-first deterministic Experience tool system; explicit/versioned/verifiable/discoverable/composable capabilities; minimal generated code.
- Human Intent intelligence and long-term personalization learning belong to EC/producer.
- Business truth/execution belong to Host.
- Runtime arbitrary generated executable code: no by default.
- Unknown capability: fail closed.
- Capability = semantic intent/contract; component = implementation asset.
- Preserve knowledge, not accidental complexity; rewrite when legacy design permanently increases LLM error surface.
- Stability order protects truth, collaboration and familiarity.
- Decision-critical mandatory evidence remains available.
- Shared reference remains stable in collaboration.
- Explicit human choice beats EC inference except policy, truth/safety, accessibility, decision integrity and collaboration constraints.
- Direct manipulation and LLM composition converge on the same constrained state/contract model.
- Attention semantic importance is distinct from device/user-specific presentation.

# Eidos Philosophy — Architecture Convergence

1. **Explicit over implicit; deterministic over convenient.** Runtime behavior follows declared contracts and explicit environment snapshots.
2. **Eidos owns experience, not enterprise truth.** Business truth and business command execution remain outside the runtime.
3. **UIDL is an external wire contract; VNode is an implementation protocol.** They must not be conflated.
4. **Components are replaceable behind stable semantic controls.** Replacing a widget must not change field or action meaning.
5. **Rendering never executes enterprise business.** Interaction produces an ActionRequest; a host confirms, authorizes and executes it.
6. **Repository contracts, ADRs and tests are authoritative.** Chat history is not an architectural source of truth.
7. **Existing implementation and history are assets.** Correct architecture boundaries before replacing working implementation.

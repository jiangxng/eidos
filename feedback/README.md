# Eidos Feedback Program

Feedback is product data. Collect structured evidence, not only opinions.

The most valuable feedback is where a human or LLM:
- misunderstood Eidos;
- selected the wrong capability;
- generated unnecessary code;
- required repeated repair;
- could not find a capability;
- disagreed with another capable LLM about a contract;
- encountered a validator gap;
- found direct manipulation slower than expected;
- found an adaptive experience unstable or distracting;
- lost shared reference in collaboration;
- found a demo claim unclear or unconvincing.

Use the templates in this folder.
